CHECK EVERY OTARI FEATURE, LIVE

Each button below makes real requests through Mozilla’s Otari gateway from this app’s server and shows what Otari answered: status, the policy asked, the model that answered and Otari’s own headers. Nothing here is a recording.

1–2. Open-weight models, several in distinct roles

Every telegram uses three open-weight models through Otari: Qwen3-235B-A22B diagnoses, Gemma 3 27B writes the Hindi/Marathi telegram, Qwen3Guard-Gen-8B judges safety. Search and the KVK tool use Qwen3-235B; field maths uses Qwen3.5-35B-A3B; the private route uses Tab’s self-hosted Huihui-Qwythos-9B. Send any telegram on the main page and open the Gateway receipt under it.

3. Routing and fallback

Policy krishi-private: Tab’s self-hosted 9B model first, then Qwen3-235B, then Gemma 3 27B. A 10,000-word field diary is longer than the small model’s context, so it refuses and Otari moves on in the same request.

4. Guardrails

Our safety floor (poisoning, self-harm and pesticide-dose rules in English, Hindi and Marathi) runs as a service and is registered in Otari as an organisation guardrail in block mode. A poisoning message sent straight to Otari is refused before any model sees it.

5. Per-user budgets

Each farmer has a daily allowance enforced by Otari (end-user budget on the app’s service key: 40 requests and US$0.05 a day). To show the refusal without waiting a day, this uses a demo key whose allowance is 1 request per farmer per day, with a brand-new farmer id each time.

6. Budgets and spending limits

The app’s service key has a US$1 monthly spend ceiling. The diagnose policy has a rule budget_used_pct ≥ 80 → Gemma 3 27B, so the app gets cheaper instead of stopping. Pushing a real key past 80% in a live button would spend the ceiling, so this one is a recorded run with Otari request ids: evidence (Qwen3-235B at 0% → Gemma 3 27B at 83%).

7. MCP

Our own MCP server (/mcp, tool find_kvk over ICAR’s 708 Krishi Vigyan Kendras) is registered in the Otari workspace. The model calls it through Otari to find a farmer’s KVK from the town they name.

8. Web search

One Otari web search for an Indian extension page. Only links that came back from the search are shown.

9. Code execution

Field maths: the model must compute with Otari code execution. Right answer: about 495,740 seedlings.
