You are building a NEW project for the Kiroween 2026 hackathon, category RESURRECTION (bring a dead technology back to life). Team lead: Akshay Wagh (Pune, India). Disclosure that must appear in the README and the app footer: "Built by Tab, an AI assistant, using Kiro, for team lead Akshay Wagh."

Product: "Last Telegram" (Krishi Telegram) — resurrect India's telegram service (BSNL shut it down on 15 July 2013) as an AI farm-advisory telegraph for low-bandwidth rural phones. A farmer types (or pastes) a long question in English, Hindi or Marathi; the app replies like a 1960s telegram: UPPERCASE, max 20 words, "STOP" between sentences, priced per word like the old service, plus a playable Morse-code audio of the reply (Web Audio API) and a printable telegram form (Halloween/ghostly vintage telegraph-office look: sepia paper, flickering candle, ghost operator).
Requirements:
- Static front end in site/ (index.html, styles.css, app.js) — no framework, accessible (labels, focus states, contrast), responsive at 390px.
- Cloudflare Worker in site/worker.mjs that serves the static assets via env.ASSETS and exposes POST /api/telegram {text, lang}. It calls the Groq OpenAI-compatible chat completions API (model "openai/gpt-oss-120b", fallback "openai/gpt-oss-20b") with key from env.GROQ_API_KEY (or a module-level SECRETS object that a deploy script fills), JSON mode, and returns {telegram, words, cost_paise, morse}. Morse encoding is done in code, not by the model.
- SAFETY FLOOR in code before and after the model: if the text mentions swallowing pesticide/poison, self-harm, or poisoning symptoms, do NOT call the model; return an emergency telegram "CALL 108 NOW STOP ..." and the 112 / Tele-MANAS 14416 numbers. If the text names a chemical pesticide or asks for a dose, reply that a KVK expert must decide; never output pesticide names or doses.
- Node tests in test/ (node --test) for: morse encoder, word counter/pricing, safety floor, and the presence of the disclosure line.
- README.md with what it is, why the telegram, how to run (wrangler dev), the Kiro workflow used (specs, steering, hooks), and MIT licence file LICENSE.

Then implement the tasks and tick them off in tasks.md. Run the tests and fix failures. Keep the code small and clean. Do not create any git commits and do not touch files outside this directory.
